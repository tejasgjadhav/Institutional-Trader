# Compare it with a coin

## The question
A rule wins fifty-eight percent of the time. Is that good?

## The method
There is no way to answer that without a baseline, so build one. Take the same entries and
replace the signal with a coin toss, keeping the same instrument, the same size, the same exits
and the same costs. Run it many times and look at the distribution of outcomes.

## What came back
The baseline is rarely fifty percent, and that is the point. Exits create the win rate. A rule
that takes a small profit quickly and lets a loss run will win most of the time on random
entries, and lose money doing it.

Several ideas that looked respectable sat inside the random distribution. They were not wrong in
any obvious way. They simply did not beat a coin wearing the same exit rules.

## What to take from it
Build the random baseline before you judge any result. Report your rule against it, not against
zero. If your rule cannot be told apart from a coin with the same exits, then what you have is
an exit rule, and you should test it as one.
